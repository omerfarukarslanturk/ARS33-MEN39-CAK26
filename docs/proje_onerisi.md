# Proje Önerisi

## Proje Adı

İşimi Buldum

## Proje Konusu

LinkedIn Jobs benzeri, web tabanlı bir iş bulma platformu geliştirilecektir. Platformda iş arayanlar ilanları görüntüleyip başvuru yapabilecek, işverenler ilan oluşturup başvuruları yönetebilecek, admin ise sistemi takip edebilecektir.

## Kullanılacak Teknolojiler

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
