# GitHub Kullanımı

Proje GitHub Classroom deposuna yüklenmek üzere düzenlenmiştir.

## Temel Akış

1. Depo bilgisayara indirilir.
2. Proje dosyaları şablon klasör yapısına yerleştirilir.
3. `python main.py` komutu ile çalışma testi yapılır.
4. Değişiklikler commit edilir.
5. GitHub'a push edilir.

## Gönderilmemesi Gereken Dosyalar

- `__pycache__/`
- `*.pyc`
- `.venv/`
- `data/job_platform.db`
