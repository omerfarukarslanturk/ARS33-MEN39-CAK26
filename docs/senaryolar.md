# Kullanım Senaryoları

## Senaryo 1: İş Arayan Başvuru Yapar

1. İş arayan kullanıcı giriş yapar.
2. İlanlar sayfasına gider.
3. Şehir, başlık veya iş türüne göre filtreleme yapar.
4. İlan detayına girer.
5. Ön yazı yazar.
6. Başvurusunu gönderir.

## Senaryo 2: İşveren İlan Oluşturur

1. İşveren kullanıcı giriş yapar.
2. İşveren paneline gider.
3. Yeni ilan oluşturma formunu açar.
4. İlan bilgilerini girer.
5. İlanı yayınlar.

## Senaryo 3: İşveren Başvuru Durumu Günceller

1. İşveren kendi ilanlarına gelen başvuruları görüntüler.
2. Adayın ön yazısını inceler.
3. Başvuru durumunu beklemede, incelendi, kabul edildi veya reddedildi olarak günceller.

## Senaryo 4: Admin Sistemi İnceler

1. Admin hesabı ile giriş yapılır.
2. Kullanıcılar görüntülenir.
3. Log kayıtları incelenir.
4. Temel rapor ekranından toplam sayılar kontrol edilir.
