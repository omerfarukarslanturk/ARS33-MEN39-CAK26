# Proje Yönergesi

Bu proje Python dersi final projesi kapsamında Flask, SQLite ve web arayüzü kullanılarak geliştirilmiştir. Amaç, farklı kullanıcı rollerine sahip web tabanlı bir iş bulma platformu oluşturmaktır.

## Beklenen Temel Özellikler

- Kullanıcı kayıt, giriş ve çıkış işlemleri
- İş arayan, işveren ve admin rolleri
- İş ilanı oluşturma, listeleme, filtreleme ve başvuru
- Başvuru durumu takibi
- SQLite veritabanı
- Log kaydı ve basit raporlama
- HTML/CSS/JavaScript ile responsive arayüz
